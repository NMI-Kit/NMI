# Approved NMI identity

13 October 2026. The user supplied the [identity board](references/nmi-approved-identity.png) in response to the request for approved logo concept #6. This reference establishes the ribbon N, four-point sparkle, cyan/blue/lavender color treatment and monochrome variants. Its labels and interface examples do not override the product specification.

The earlier geometric placeholder has been replaced. These are hand-built SVG adaptations of the supplied raster reference, not an original designer vector export or a claim of pixel-exact tracing. Every asset is icon only, transparent, self-contained, script-free, and uses the same geometry. No font or external resource is required.

| File in preview/assets | Usage |
|---|---|
| nmi-mark-light.svg | Colored icon on light interfaces, with a slightly deeper sparkle. |
| nmi-mark-dark.svg | Colored icon on dark interfaces, with brighter cyan highlights. |
| nmi-mark-white.svg | White/grayscale ribbon variant for dark backgrounds. |
| nmi-mark-black.svg | Black/grayscale ribbon variant for light backgrounds. |
| nmi-mark.svg | Default colored compatibility asset; matches light variant. |

The preview switches the light/dark color asset with its own theme preference, including the favicon and dynamically created assistant messages. Sidebar and welcome logo treatments contain no wordmark. NMI text in navigation and assistant attribution remains ordinary product text. Logos do not mirror when switching to Arabic. Accessible names are on the brand link or meaningful image; redundant decorative images have empty alternative text.

Keep the surrounding interface quiet. The mark's approved gradient is the sole branded gradient; do not add cosmic backgrounds or perpetual glowing effects. The welcome entrance is a brief transform, disabled by reduced-motion preferences. The supplied animation strip provides ideas rather than a requirement to run every effect at once.

The reference PNG is documentation only and is not served by the loopback preview server. Only the named SVG variants are added to its static allowlist.
